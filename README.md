# MIT Meta Ultimate

OpenCourseWare study desk for MIT-style master's programs, Harvard–MIT HST and residency, and the EECS Einstein track.

41 programs, 218 courses. Filter by school, search a code, follow a semester roadmap, and mark 90-minute lecture blocks. Progress stays in the browser. At 100% the desk says you are at the certificate-equivalent spot.

This is an educational preview. It does not issue a degree, credit, or an MIT or Harvard credential.

## Run

```bash
npm install
npm run dev
```

Open the local dev server (port 8080).

## What you can do

- Browse Engineering, Sloan, Architecture, Science, HST / residency, and the EECS Einstein track.
- Watch a related public lecture when one exists (MIT OpenCourseWare or 3Blue1Brown). Clinical and thesis blocks are self-reported.
- Download a problem-set bundle that points at the public source pages.
